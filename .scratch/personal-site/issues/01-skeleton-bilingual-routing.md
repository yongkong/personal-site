# 01: 站点骨架与双语路由打通

**What to build:** 全新 Next.js（App Router）+ TypeScript + Tailwind + shadcn/ui 代码库（pnpm），静态导出。`/`（默认 en）与 `/zh` 通过真实内容管线渲染首页：UI 文案按 locale 组织，含占位定位语；页头/导航/页脚完整双语；深浅色模式跟随系统且可手动切换、选择持久化。测试接缝就位：构建后断言脚本进入 CI，验证双语路由存在且各自渲染对应语言文案。站点基础配置（站名、作者署名占位）集中管理。遵循 ADR-0001（无数据库、静态化）、ADR-0002（默认 en，`/zh`）。

**Blocked by:** None（可立即开始）
