# 02: Blog Post 集合

**What to build:** 开发心得（Blog Post）MDX 集合与页面：英文 `/blog` 列表 + `/blog/<slug>` 详情，中文 `/zh/blog` + `/zh/blog/<slug>`。核心行为：每个语言版本的列表只显示该语言已有的文章——用一篇仅中文的占位心得和一篇英文占位心得证明规则。正文排版支持 MDX 常用元素（标题层级、代码块、引用、列表）。

- [ ] 仅中文的文章出现在 `/zh/blog` 列表且不出现在 `/blog` 列表
- [ ] 正文排版正常渲染 MDX 常用元素
